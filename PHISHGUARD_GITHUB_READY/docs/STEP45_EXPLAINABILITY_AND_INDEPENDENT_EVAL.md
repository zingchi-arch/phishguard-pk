# Step 45 | Model Explainability and Independent Evaluation

Date: 2026-11-02. This is **research software with unverified training labels**, not a certified fraud detector.

## Completed in this patch

1. `POST /analyze/explain` computes bounded **model-based local token deletion sensitivity** using the loaded `text_model.joblib` classifier. This is an opt-in endpoint. The default `/analyze` and `/analyze/batch` remain unchanged. Up to 900 characters and 16 tokens are analyzed; no URLs are fetched. Response includes `model_attribution`, top positive/negative changes to the classifier's **Scam-class score**, and explicit limits. The output explains **the text classifier only**, not the final combined verdict, which may be overridden by Pakistani context and URL rules.
2. `scripts/step45_shap_lime_explain.py` runs **real SHAP** or **LIME** locally, using the optional external libraries, on the research text model. The script saves CSV/JSON outside the repository to `~/phishguard_step45_private_explain/`. For genuine SHAP, it uses a text masker and Partition algorithm. For genuine LIME, it uses `LimeTextExplainer` and the model's `predict_proba`. SHAP was smoke-tested locally on a Roman Urdu scam example; LIME execution requires the optional package and was not verified in this workspace because the package could not be downloaded here.
3. `scripts/step45_independent_test_gate.py` validates a **future** independently collected 50-100-example three-language holdout for declared reviewer metadata, non-synthetic source types, exact and TF-IDF near duplicates, and overlap against a **required real development corpus**. It then generates accuracy, per-class metrics, per-language metrics, and confusion matrix. The script cannot authenticate the source claims or reviewer identity by itself, so human/source evidence validation is still required.

## How to use the API

After deploying this patch, with an existing authenticated/known demo environment:

```text
POST /analyze/explain
Content-Type: application/json

{"message":"Apka account band hai, foran OTP bhejein"}
```

Compare `model_attribution` with `explanation`. A high rule-based scam verdict can coexist with weak text-model evidence: the model explanation **does not explain the rule floor**.

**Do not call this expensive endpoint for every item in CSV batches or make it a public high-throughput service without rate limiting.** Deployment status must be checked in Vercel. It is a bounded research endpoint, not independently security-audited.

## Real SHAP and LIME (local optional research)

```sh
pip install shap lime
python scripts/step45_shap_lime_explain.py --method shap --message 'Apka account band hai, OTP bhejein'
python scripts/step45_shap_lime_explain.py --method lime --message 'Your OTP is 123456. Do not share it.'
```

Do not upload resulting local CSVs to GitHub: they may contain original personal message tokens. The SHAP/LIME explanations are *not* generated by the live API; live uses clearly identified deletion sensitivity. Attribution is for the development **text classifier class**, not for the final hybrid risk indicator.

## The university's independent 50-100 message evaluation is NOT complete

Template: `docs/STEP45_EXTERNAL_50_100_TEMPLATE.csv`.

Required fields are: `message,label,language,source,source_type,source_url_or_document,independent_reviewer_id,review_date,rights_or_consent,verified_by_reviewer`.

Accepted `source_type`: `recipient_consent`, `published_public_message`, or `institutional_case_report`. Accepted `rights_or_consent`: `CONSENT`, `PUBLIC_SOURCE_WITH_CITATION`, `LICENSED_DATA`. Reviewer must actually review original evidence (do not fill `YES` by script). Source quality and legal reuse rights must be independently confirmed. Keep recipient data private, remove phone numbers and other identifying information; redaction should not alter the fraud behavior essential to the label.

```sh
python scripts/step45_independent_test_gate.py \
  --input path/to/actual_50_to_100_reviewed_messages.csv \
  --development path/to/the_actual_training_corpus.csv
```

The previous 100 auto-triaged messages and the teacher's synthetic examples **cannot be substituted**. No fake final accuracy should be reported.
