# Boss, PhishGuard v2 ka easy start

1. **PHISHGUARD_V2_COLAB.ipynb** ko Google Colab me upload karo.
2. **Runtime -> Run all** dabao.
3. Colab jab ZIP maange, **PHISHGUARD_V2_FULL_SOFTWARE.zip** upload karo.
4. Last cell me **gradio.live** blue link khol lo, aur woh cell chalne do.
5. Website me English, Roman Urdu ya Urdu ka message paste karo. **Batch CSV** tab se ek baar me 100 tak messages check karo.

Full website local computer par chahiye to project ZIP extract karke `pip install -r requirements.txt` aur `python run_web.py` chalao. Browser me `http://127.0.0.1:8000` kholo.

**Yaad rakho:** Ye functioning FYP software hai. Text models ke training labels abhi provisional hain, URL classifier independent real data par trained nahi, aur XLM-RoBERTa GPU fine-tuning pending hai. Final university research results ke liye independently reviewed data aur genuine final test zaroori hai. Fake numbers report mat karna.
